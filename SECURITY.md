
# Security Policy

## Supported Versions

Security updates will be provided for the latest stable release of CNCVerse-Bridge, where reasonably possible.

## Reporting a Vulnerability

If you discover a security vulnerability in CNCVerse-Bridge, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub Issues.**

Instead, use GitHub's private vulnerability reporting feature, if enabled for this repository, or contact:

**Security Contact:** [YOUR SECURITY EMAIL]

When reporting a vulnerability, please include:
- A clear description of the issue.
- Steps to reproduce the issue.
- The potential impact.
- Relevant logs or proof-of-concept details, with secrets and personal data removed.

## Responsible Disclosure

Please allow the maintainer reasonable time to investigate and address a reported vulnerability before publicly disclosing technical details.

Do not access, modify, or delete other people's data while testing a suspected vulnerability.

## Response and Remediation

Reports will be reviewed as time and resources permit. The maintainer will assess valid reports and determine appropriate remediation.

Response times and fixes are not guaranteed.
